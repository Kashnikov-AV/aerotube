# aerotube

Симуляция аэродинамической трубы методом решетки Больцмана (Lattice Boltzmann Method).

## Описание

Проект представляет собой интерактивную симуляцию потока жидкости/газа вокруг различных препятствий с использованием метода решетки Больцмана. Приложение построено на PyQt6 с использованием библиотеки pyqtgraph для визуализации.

## Возможности

- Визуализация различных параметров потока:
  - Плотность
  - Скорость по оси X
  - Скорость по оси Y
  - Полная скорость
  - Завихренность
- Различные типы препятствий:
  - Без барьера
  - Простой барьер
  - Квадрат
  - Цилиндр
  - Профиль крыла
- Несколько цветовых схем для визуализации (16 вариантов)
- Расчёт сил воздействия потока (Fx, Fy, F)
- Интерактивный интерфейс с возможностью запуска, остановки и сброса симуляции

## Требования

- Python 3.x
- NumPy
- PyQt6
- pyqtgraph

## Установка зависимостей

```bash
pip install numpy PyQt6 pyqtgraph
```

## Запуск

```bash
python main.py
```

## Структура проекта

- `main.py` — основной файл приложения, класс интерфейса
- `engine.py` — движок симуляции, реализация метода решетки Больцмана
- `utils.py` — вспомогательные утилиты (цветовые схемы)
- `design.ui` — файл интерфейса Qt Designer

## Параметры симуляции

- Размер сетки: 200×80 узлов
- Вязкость: 0.005
- Начальная скорость потока: 0.03
